# VEILWARD — THE HOLLOWREACH SLICE (canonical roadmap)

## Scope promise
Build and perfect one small but complete action-RPG pocket. No full-game roadmap until the creator approves the polished vertical slice.

## Golden visual reference
The screenshot supplied by the creator (snowy cliffs, cottage, bridge, small player, warm lanterns) is the quality benchmark regardless of biome. The exact rendering language takes priority over generic procedural game graphics. See ART_BENCHMARK.md.

## Playable area
- Hollowreach frontier village with shop, forge, inn, guards and two visitable homes.
- Connected forest route and wildlife.
- Bandit cave and ancient ruin with meaningful loot and exploration puzzles.
- Secrets and side paths that reward curiosity.
- Movement, interiors and camera that work with landscape iPhone Safari.

## Gate 0 — Preproduction ✅
Choose art standard, world tone, technology and milestone boundaries. Vanilla web game, static GitHub Pages hosting; no paid service or external dependencies.

## Gate 1 — Art foundation and movement 🚧
Deliver actual pixel tiles/sprites, terrain height, roof facades, high-detail props, camera, controls, clipping/collision and readability. Current v0.1 has working maps + movement with procedural placeholder imagery, **not** approved reference fidelity.
Pass only when creator explicitly approves *actual gameplay screenshots* from village, forest, interior and combat.

## Gate 2 — Combat vertical slice
Responsive melee/shield, bow, 3 spells, dodge and meaningful telegraphs. Wolves, bandits, ancient dead and one elite, animations for hit, stagger, deaths; mobile input reliability.
Current v0.1 includes preliminary sword, spell, dodge, hitpoints, wolves, bandits and wraith; full mechanics and balance not complete.

## Gate 3 — Core RPG loop
Skill-use XP/perks, equipment choice, meaningful loot, vendors, harvesting, functional blacksmith/alchemy/cooking and robust saves. Current v0.1 includes basic leveling, vendors, gathering, potions, gold, local saves.

## Gate 4 — Living world and quests
NPC schedules, dialogue branches, crime/guard response and lasting consequences. Main introductory quest, 3 substantial side quests, an ancient shrine puzzle, exploration secrets, weather and day/night. Current v0.1 only pilots dialogue, first quest and atmosphere.

## Gate 5 — Cohesion and art pass
No generic placeholders, no broken UI, no mismatched sprite scales or lighting styles. Clear iconography, game audio, animation polish, responsive controls, balancing, difficulty and performance.

## Gate 6 — User approval
Hands-on playtest and repeated polish rounds. Confirm 30–60 minutes of satisfying real RPG content; correct persistence, no critical bugs; stable iPhone Safari and Add-to-Home-Screen operation; gold-reference-consistent graphics across winter/greenery/interior. Explicit creator approval required **before** expanding the full-game roadmap.

## Non-negotiables
- No Codex, Work, Vercel, paid APIs or server dependencies.
- Source stays in the user's GitHub repo; GitHub Pages serves static single-player game.
- Use source tiles, sprite sheets and runtime screenshots; concept images never count as implemented assets.
- Always disclose which features are real versus planned.
- Do not skip art sign-off to add quantity of content.
